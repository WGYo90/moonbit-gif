# Changelog

## [0.1.0] - 2026-08-19

- Added pure MoonBit GIF87a/GIF89a parsing and GIF89a encoding.
- Added Median Cut palette quantization, ordered/Floyd–Steinberg dithering, and dynamic LZW.
- Added RGBA canvas drawing, geometry, sampling, animation timeline tools, disposal composition, and frame patch analysis.
- Added runnable CLI example, black-box tests, strict cross-platform CI, project proposal, and Apache-2.0 licensing.
